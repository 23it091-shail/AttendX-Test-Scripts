
# AttendX Test Scripts

This repository contains sample automated unit tests for the
AttendX Student Attendance Application.

## Test Scripts

1. test_login.py
   - Tests valid student login.
   - Tests invalid login credentials.

2. test_attendance.py
   - Tests valid attendance marking.
   - Tests invalid attendance status.

## Requirements

- Python 3.x
- Git

## Run Tests

python -m unittest discover -p "test_*.py" -v

## Version Control

Git is used to track changes in test scripts.
GitHub is used for remote repository collaboration.
